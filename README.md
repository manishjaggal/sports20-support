# Sports app support site

Public-facing static support and privacy pages for twenty independent sports apps. Deploy this directory as the site root. No deployment has been performed by this preparation task.

- `index.html` links to all apps.
- `manifest.json` records every support, privacy and icon path. Set the real base URL only after deployment is verified.
- Each brand directory contains `support.html`, `privacy.html` and its app icon.
- `style.css` is shared, responsive and uses system fonts. No JavaScript, analytics, tracking pixels, forms or external asset dependencies are included.
- `.nojekyll` supports direct static hosting.

The directory intentionally contains no application source, fixtures, simulator data or private build artifacts. Copy only this directory for hosting. All contact links use the user-provided powerpassive46@gmail.com address; no legal entity, postal address or deployed URL is invented.

Content is based on the implemented apps and audited release metadata where available. External reference links are identified for Crease (MCC), Sixside (FIVB), Split (Concept2) and Platform (IWF). App-local data is distinguished from user-directed exports, device backups, email correspondence and ordinary website-hosting request processing.
